# Original art preserved + independent Type-Linked (文字联动) lettering · 4 posters

[Back to the style guide](../../../styles/type-linked/STYLE.md) · [Full gallery](../../../GALLERY.md#动态海报展厅)

<img src="01-rin.gif" alt="Kagamine Rin's figure linked with an independent type layer" width="480">

Kagamine Rin (镜音铃) switches from a relaxed smile to singing into a microphone; the RIN at the top expands from tight outline lettering into solid lettering, and the separate TURN IT UP type layer steps up in size, offset and tilt. Date and venue are fixed. 720×960, 6-second infinite loop.

This version has been accepted by the user and is the sample for the regular type-linkage route; it keeps the original illustration art style and is distinct from the later screen-print versions where the whole poster is redrawn. The figure comes from an earlier pose comparison sheet generated from character references; this type linkage did not regenerate the character. Only the finished pieces are published here; the type-layer project files are not bundled.

The show information is a fictional concept, not an official event; character and font rights are not transferred with the code.
